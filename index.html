支持的格式

CSV / Excel 另存（表头含「题名 / 篇名 / 刊名 / 被引次数」等知网、万方列名均可）、BibTeX（PubScholar / Zotero / 万方通用，.bib）、EndNote·RefWorks·NoteExpress 标签格式（TI/T1、AU/A1、PY/YR、SO/JF、AB、KW）、JSON 数组、PDF 文献文件（自动提取标题/作者/年份等元数据）、以及直接复制的结果页文字（尽力解析）。

导出文件若不含下载量 / 被引量 / 层次，这几项筛选对导入题录不生效；深度审查会把缺失字段一律标成「需人工核验」，不会编造实验细节。

请遵守学校图书馆与知网的使用条款：仅限本人账号、仅限教学科研用途、不要批量抓取或分发全文。导入数据只保存在本机浏览器，不会上传。

接入设置

原型默认使用内置演示数据 + 本地审查引擎，离线即可完整演示。接上真实服务后，检索与分析仍然是分开的两层。

关于学校 WebVPN（hdu.edu.cn）

WebVPN 需要你在浏览器里用学校账号交互式登录，会话 Cookie 只属于你当前的浏览器，前端页面无法复用，也绝不要把账号密码写进代码或配置。推荐做法是登录后用知网站内「导出题录」，再点顶部「导入题录」（PubScholar / 万方同理）。

若要做成自动检索，请由本机后端实现 POST /api/search：会话凭据只放后端环境变量，仅转发你手动发起的单条检索、仅取题录元数据、不批量抓取、不下载全文，返回 { items: [Paper], note } 即可。前端选「自定义检索接口」就能接上。

浏览器直连第三方 API 可能遇到跨域限制，正式部署请走后端代理。知网没有面向个人的公开检索 API，请勿依赖爬虫抓取；合规接入方式见 README。

三步上手

1 · 找论文

直接输入关键词，或把「学校 / 层次 / 下载量 / 年份 / 引用 / 语言」写进同一个检索式，系统会自动解析成筛选条件。这一步是纯检索，不会调用大模型。

2 · 选文献

结果卡片显示层次、机构、下载与被引。可加入对比篮（最多 5 篇），也可以对单篇直接操作。

3 · 定强度

轻度审查≈30 秒读懂一篇：三句话概要、术语速查、适合谁读。深度审查按来源/方法/数据/引用/结论五步核查，附创新点、局限与待核验清单。英文论文可一键中译，「引用」按钮直接给 GB/T 7714 与 BibTeX。

4 · 带走结果

报告可导出 PDF 或 Markdown 笔记；多篇对比会给出共同点、差异矩阵与综述骨架。
